===============================================================================
REQUERIMIENTOS FUNCIONALES
===============================================================================

RF-01: El sistema debe permitir administrar torneos, clubes, estadios, jugadores, entrenadores y árbitros mediante distintos niveles de operación (Alta, Baja y modificación).
RF-02: El sistema debe permitir inscribir clubes en un torneo determinado.
RF-03: El sistema debe generar de forma automática o manual el fixture completo de un torneo.
RF-04: El sistema debe permitir programar un partido asociando los dos clubes (local y visitante), la fecha, el estadio y la terna arbitral.
RF-05: El sistema debe registrar en tiempo real los eventos ocurridos durante un partido en juego (goles, remates, tarjetas amarillas/rojas, cambios y faltas).
RF-06: El sistema debe permitir cerrar un partido una vez finalizado el tiempo reglamentario, registrando su resultado definitivo.
RF-07: El sistema debe disparar notificaciones automáticas ante goles, tarjetas rojas y finales de partido a través de los canales de comunicación configurados.
RF-08: El sistema debe gestionar el ciclo de vida de los contratos de los jugadores, incluyendo el alta, las transferencias entre clubes y las rescisiones.
RF-09: El sistema debe gestionar los acuerdos de patrocinio (sponsors) vigentes para clubes y torneos.
RF-10: El sistema debe calcular y emitir el reporte de la tabla de posiciones del torneo bajo las reglas de puntuación y desempate oficiales.
RF-11: El sistema debe emitir la tabla de goleadores del torneo.
RF-12: El sistema debe emitir el reporte de la valla menos vencida.
RF-13: El sistema debe calcular las métricas estadísticas de rendimiento, específicamente los goles esperados (xG) de remates, jugadores y clubes.
RF-14: El sistema debe calcular la probabilidad de clasificación de los clubes empleando diferentes métodos intercambiables.
