DESCRIPCIÓN GENERAL DEL SISTEMA:
FutbolStats es un sistema de gestión administrativa de un único torneo de fútbol profesional,
cuyo objetivo es centralizar toda la información del torneo, sus clubes, planteles, jugadores, árbitros,
partidos y eventos. Una vez finalizado dicho torneo, el sistema permite archivar y conservar en un historial de 
torneos. La información del gestor se guarda y recupera mediante serialización de objetos Java en archivos binarios.
Este sistema permite inscribir clubes mediante la presentación de un plantel de entre 18 y 30 jugadores, 
generar automáticamente un fixture de todos contra todos con partidos de ida y vuelta, programar encuentros,
asignar estadios y ternas arbitrales, y registrar los eventos que ocurren durante los partidos.
Además, ofrece distintas herramientas para administrar contratos de jugadores, patrocinios y sanciones disciplinarias. 
A partir de los datos del torneo, se puede generar las tablas de posición, rankings de goleadores,
estadísticas de rendimiento y proyecciones deportivas, incluyendo goles esperados (xG) y
probabilidades de clasificación. Por último, el sistema tiene un mecanismo de notificaciones 
que informa al usuario sobre los acontecimientos relevantes de los partidos 
mediante diferentes canales de comunicación. También contará con una interfaz de consola organizada mediante el MVC, 
separando responsabilidades presentación, coordinación y lógica de negocio.
